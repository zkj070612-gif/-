# LaTeX 模板

`main.tex` 是可以直接编译的论文骨架，`easymcm.sty` 是它依赖的样式文件（从你原有仓库里复制的，西安交大的 EasyMCM v5.1）。我用 pdfLaTeX 和 XeLaTeX 各编译过一遍，都通过，输出 8 页。

## 在 Overleaf 上用

1. New Project，选 Blank Project。
2. 把项目里自动生成的 `main.tex` 删掉，上传这里的 `main.tex` 和 `easymcm.sty`。
3. 新建一个文件夹，名字叫 `figure`，图片都放里面。
4. 点 Recompile。编译器保持默认的 pdfLaTeX 即可。

## 注意

- **`main.tex` 里不要写中文**，注释也不要。pdfLaTeX 遇到中文字符会报错。
- 仓库里的 `template.tex` **不是可编译的文档**，它是一份常用代码片段的备忘（列表、三线表、并排图片等写法），里面还夹着中文说明。需要某种写法时打开它，把对应片段复制到 `main.tex` 里用。
- 队号在第 9 行 `\usepackage[0000000]{easymcm}` 里改，题号在 `\problem{A}` 里改。
- 图片文件名不要带空格和中文。引用时写文件名即可，不用写 `figure/` 路径。
- 页眉右侧的总页数会把文末的 AI 使用报告也算进去。规则是正文不超过 25 页、AI 报告另计，提交前自己数一下正文页数。
- 摘要页的年份取的是编译当天的年份，比赛时会自动显示 2027。
- 这个样式是按 2020 年的 Summary Sheet 做的。比赛开始后对照官网当年发布的摘要页样式看一眼，有出入就手动调。
